# 产品要求

DevKit 是面向 Web 开发者的原生 macOS 工具箱，最低系统为 macOS 26。完整工具箱是主体，Spotlight 是适合短文本与轻量操作的快捷入口，两者共享核心算法。

## 功能与组织

- 以[工具目录](tool-catalog.md)中的注册入口为范围，一个工具一个功能目录；编码/解码和算法选择保留在同一工具内。
- 提供搜索、收藏、输入输出对照、参数配置、示例、复制、文件导入导出和独立窗口。
- 侧栏切换保留内存会话，不以后台挂载全部页面来保存状态。
- 原生 SwiftUI/AppKit 控件优先；窗口材质、主题与辅助功能跟随系统。
- 先满足个人日常使用，公开发布的渠道、许可证和商业模式另行确定。

## 数据与结果

输入中的空格、换行、大小写、Unicode 和数值精度必须按工具约定处理。不能统一裁剪原文，也不能把预览截断当成真实结果。

输入或参数变化使旧结果失效；失败清除旧结果，异步过期任务不能覆盖新状态。随机生成、联网、写文件和剪贴板操作由用户明确触发。Base64 是编码，JWT 解析、签名和业务声明检查必须区分。

偏好和收藏可持久化，正文、密钥和网络凭证默认只在内存中。网络能力只属于明确的联网工具，不由文档预览或远程引用隐式触发。

## 系统入口目标

Spotlight 同时保留整行命令与引导式操作目标；允许首次手动配置 Quick Key。结果在系统界面显示，由用户点击复制，普通快捷操作不抢主窗口焦点。完整体验需系统端验证，不能以动作可发现或单元测试替代。

## 范围边界

当前项目不扩展为完整 IDE、浏览器、数据库平台、团队 API 协作平台或任意代码执行器。账号同步、插件市场和云端处理不是基础功能的前提。实际支持范围与未完成项以[实现范围](implementation-status.md)为准。
