# 视觉约束

主窗口使用 `NavigationSplitView`、系统工具栏与 `.inspector`。侧栏以原生 `.sidebar`、`.behindWindow` 材质绘制内缩面板；红绿灯由系统管理。工具名称为窗口标题，不额外展示说明副标题。

## 内容与层次

- `WorkspaceMetrics` 统一侧栏宽度、内边距、面板间距与圆角，修改前检查所有共享布局。
- 编辑器和结果面板保持连续、稳定的背景；原生文本控件不重复绘制独立方形背景。
- 窗口工具栏使用系统材质，内容区使用轻量原生按钮，不在候选布局上叠加多层玻璃。
- 分类图标与少量动作可用局部颜色；正文、背景、边框和状态使用语义色，兼容深浅外观。
- 输入、输出与第二输入的标题、操作栏和状态区保持对齐。

## 系统适配

侧栏固定宽度，通过按钮或快捷键收放；内容对照面板允许用户调节比例。窄窗口切换完整输入或结果视图，编辑器不能反向撑大窗口。

减少透明度时使用语义背景；减少动态效果时关闭布局动画。主题在主窗口、设置、独立窗口与 AppKit 控件中一致传播，不读取或写入私有系统偏好。

检查长标题、长错误、空态、大结果、字体放大和键盘焦点。视觉改动需在 Xcode 当前 Run 的应用中核对，不能仅以截图或编译成功判断交互正确。
