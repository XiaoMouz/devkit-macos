# Spotlight 约束

Spotlight 是主工具箱的快捷入口，默认关闭。应用设置管理总开关、支持工具的独立开关和本应用索引。每个工具页只展示开关、命令示例和支持的操作；首次使用、系统 Quick Key 和排错说明集中在页面右上角的“Spotlight 使用帮助”。不提供快捷短语、备忘或命令别名编辑器，Quick Key 由用户在系统 Spotlight 设置。旧版本保存的别名仅保留解析兼容。

## 入口与执行

公开动作包含 `Base64 命令`、`Base64 编码或解码`、`DevKit 命令` 和 `DevKit 工具操作`。旧动作类型可保留兼容身份，但不应重复公开发现。实际可发现性和必填参数以 App Intents 源码与构建元数据为准。

命令式入口接收工具、操作和载荷；Base64 独立入口也接受已由系统提供工具上下文的 `编码 hello` 或 `encode hello`。解析保留载荷的空格、Unicode 和尾部换行，不执行 Shell、不展开变量。

```text
base64 编码 hello
base64 解码 aGVsbG8=
base64 编码 --
```

命令示例和操作名称跟随应用语言；解析接受所有已安装翻译资源中的操作词，包括带空格的短语。英文原始选项值和 enc / dec / fmt / min 简写始终兼容；原始命令优先，翻译短语按最长完整边界匹配，有歧义时拒绝执行。工具 ID、动作 ID、选项值保持稳定，不翻译载荷。新增语言仅需翻译 JSON 资源，无需增加语言分支。

引导式入口收集工具、操作与必要参数。两类入口调用共享核心，结果只计算一次，卡片刷新不重复生成随机值或改写剪贴板。点击复制取得完整结果，不受展示截断影响。

Spotlight 可以临时启动没有窗口的主进程。执行、查询、卡片与复制入口均登记活动，结束后释放；无窗口且无活动 15 秒后正常退出，后台期间显示临时菜单栏入口。重新执行或复制时系统可再次启动应用，结果卡片的数据由 Intent 参数携带，不依赖上一个进程的内存。隐藏/最小化的已有工作窗口不触发自动退出。无窗口启动不启动更新检查或重新同步索引。不能为了出现在系统「允许在后台」列表中而注册无实际需要的常驻服务。

## 开关与索引

执行前后都应检查工具权限。关闭时拒绝解析和执行，只清理 DevKit 索引；索引同步串行化，已成功关闭的状态避免重复清理。系统可能继续保留编译期动作名称，应用不能保证立即消失。

索引只保存工具元数据，不包含用户正文。不能代替用户写入系统 Quick Key，也不能清理整个系统 Spotlight 数据库。

## 验证边界

系统动作需要有效开发者签名，签名由 Xcode 维护。Debug 使用 `DevKit Debug` / `app.devkit.macos.debug`，Release 使用 `DevKit` / `app.devkit.macos`；索引和偏好按 Bundle ID 隔离。选择动作时核对来源应用。避免开发签名与 Developer ID 分发版共用同一 Bundle ID 而被 Spotlight 拒绝连接。动作可发现、索引同步成功、直接调用核心和元数据检查，都不能证明完整系统交互通过。

需要分别验证整行命令、引导输入、配置 Quick Key 前后共存、空载荷、Unicode、尾部换行、超限错误、结果复制，以及应用未运行/运行中/无主窗口时的焦点表现。完整系统体验仍是开放验证项，不能改写为已完成能力。
