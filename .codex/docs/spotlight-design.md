# Spotlight 约束

Spotlight 是主工具箱的快捷入口，默认关闭。应用设置管理总开关、支持工具的独立开关、命令别名和本应用索引；别名与系统 Quick Key 是不同配置。

## 入口与执行

公开动作包含 `Base64 命令`、`Base64 编码或解码`、`DevKit 命令` 和 `DevKit 工具操作`。旧动作类型可保留兼容身份，但不应重复公开发现。实际可发现性和必填参数以 App Intents 源码与构建元数据为准。

命令式入口接收工具、操作和载荷；Base64 独立入口也接受已由系统提供工具上下文的 `encode hello`。解析保留载荷的空格、Unicode 和尾部换行，不执行 Shell、不展开变量。

```text
base64 encode hello
base64 decode aGVsbG8=
base64 encode --
```

引导式入口收集工具、操作与必要参数。两类入口调用共享核心，结果只计算一次，卡片刷新不重复生成随机值或改写剪贴板。点击复制取得完整结果，不受展示截断影响。

## 开关与索引

执行前后都应检查工具权限。关闭时拒绝解析和执行，只清理 DevKit 索引；索引同步串行化，已成功关闭的状态避免重复清理。系统可能继续保留编译期动作名称，应用不能保证立即消失。

索引只保存工具元数据，不包含用户正文。不能代替用户写入系统 Quick Key，也不能清理整个系统 Spotlight 数据库。

## 验证边界

系统动作需要有效开发者签名，签名由 Xcode 维护。动作可发现、索引同步成功、直接调用核心和元数据检查，都不能证明完整系统交互通过。

需要分别验证整行命令、引导输入、配置 Quick Key 前后共存、空载荷、Unicode、尾部换行、超限错误、结果复制，以及应用未运行/运行中/无主窗口时的焦点表现。完整系统体验仍是开放验证项，不能改写为已完成能力。

详细用例见[测试要求](acceptance-plan.md)，当前操作说明见[行为参考](user-guide.md)。
