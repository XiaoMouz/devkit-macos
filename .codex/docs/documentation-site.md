# 文档站维护

## 页面与语言

`docs/` 是 VitePress 用户手册，发布到 `https://luolayo.github.io/devkit-macos/`。中文使用根路径，英文使用 `/en/`；两种语言的文章保持相同相对路径，语言切换保留当前文章。根目录 `README.md` 与 `README.en.md` 互相链接。

`docs/.vitepress/tool-catalog.json` 是分类、工具 ID、中英文名称和摘要的共同来源，供侧栏和首页工具目录读取。新增工具或修改参数时，同步中文与英文工具页、目录和相关指南。

公开内容聚焦功能、安装、操作、示例和必要限制。下载链接指向 Releases 的 latest 入口；具体版本号放在版本说明和对应 Release。平台要求集中在安装文档，不在首页重复堆放。开发内部约束、签名细节、验收流水和临时调试记录不放入用户教程。

## 首页组件

所有组件位于 `docs/.vitepress/theme/`。

| 文件 | 职责 |
| --- | --- |
| `Home.vue` | 双语首页、章节导航、滚动场景和截图查看 |
| `SoftwareDemo.vue` | 六种工具的浏览器交互、会话、外观和复制 |
| `demo-tools.mjs` | 演示数据、有限范围的转换和 JSON 着色片段 |
| `ToolCollections.vue`、`tool-search.mjs` | 分类目录、全角与多关键词搜索、排序和工具跳转 |
| `TerminalDemo.vue`、`terminal-examples.mjs` | 有限次数的命令播放与对应结果 |
| `DemoIcon.vue` | 演示界面的图标 |
| `custom.css` | 教程样式、首页布局、响应式规则与交互状态 |
| `software-demo.css` | 浏览器工作台的局部布局与配色 |

首页使用统一深色展示风格，浏览器工作台可切换外观。演示仅覆盖声明的操作，不代替原生核心的完整能力和边界；参数、精度和格式范围以应用工具文档为准。终端区域只展示示例命令与计算结果，不执行 Shell、CLI 或网络请求。

目录结果直接链接到工具文档。六个演示工具另有试用入口，定位到工作台并保留已有会话。`/` 聚焦搜索的快捷键不拦截编辑器或弹层输入；搜索结果变化后需刷新滚动场景的位置。

## 动效与无障碍

GSAP 与 ScrollTrigger 按需加载。首屏工作台随滚动调整位置，JSON、编码转换和图片场景按进度切换。宽度至少 760px 且高度至少 620px 时启用滚动固定；窄屏、矮屏和减少动态效果模式使用正常文档流。

场景圆点保留无障碍名称，非当前固定场景保持 inert。截图完整呈现工作区，放大后支持按钮和方向键切换。默认 HTML 必须可读，完整目录入口始终可达。

终端播放支持暂停、继续、重播及单例选择；离屏或标签页隐藏时暂停，减少动态效果时直接展示结果。使用固定高度画布与细进度条，CLI 区域保持 `overflow: clip`，避免内部控件聚焦造成额外滚动。

组件卸载时清理时间线、ScrollTrigger、IntersectionObserver、媒体查询和可见性监听。切换语言或离开首页不能留下重复监听与滚动固定占位。

## 截图与资源

正式截图位于 `docs/public/images/`，来自 Xcode 当前 Run 的应用并使用可公开样例。英文教程标明截图所用语言，不合成翻译后的应用截图。网站图标 `devkit-icon.svg` 由应用 Icon Composer 图层组合，应用图标变化时同步维护。

临时页面样稿、翻译脚本、截图和检查输出放在被忽略的 `build/` 或仓库外；已确认的页面、演示源码、正式资源和回归测试需要入库。

## 验证与发布

`npm test --prefix docs` 检查双语页面对应、48 个工具的参数与目录、演示转换、终端示例和搜索行为。`npm run build --prefix docs` 检查构建及内部 Markdown 链接；同时检查产物中的锚点和资源引用。

涉及布局或动效时，还应核对窄屏、减少动态效果、键盘导航、语言切换和离开首页后的清理。纯文档整理不需要重建原生应用。命令与部署入口见[开发维护](development.md)。
