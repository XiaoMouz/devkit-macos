# DevKit 数据处理与权限

## 默认处理方式

文本、生成、格式和图片工具优先在本机完成。HTTP、WebSocket 和 DNS 等联网工具只有在用户明确发送、连接或查询时才联网；“全部离线”不能作为包含这些功能后的整体宣传语。

应用不默认注册账号，不默认上传输入、输出、诊断或使用统计。发布更新检查若后续加入，需要独立说明其请求内容和关闭方式。

## 数据分类

| 数据 | 默认行为 |
| --- | --- |
| 外观、收藏、常用非敏感参数 | 可保存在本机偏好中 |
| 当前会话输入与结果 | 保存在当前内存会话；默认不跨启动恢复 |
| 密钥、密码、JWT、Authorization、Cookie | 不写入通用历史和诊断日志，不自动填入跨会话默认值 |
| 手动复制内容 | 写入系统剪贴板；后续保存和同步受系统及用户的剪贴板管理器控制 |
| 用户导出文件 | 仅写入用户选择位置，默认不覆盖源文件 |
| 用户发起网络请求 | 发送至明确显示的目标；内容以当前请求配置为准 |

如果以后提供“保存工作区”，需要区分元数据与正文，提供清晰的保存范围和敏感字段策略；不能把恢复工具列表等同于同意保存所有内容。

## 剪贴板

读取只由“粘贴”、明确的导入操作或系统传入的动作参数触发。默认不监听全局剪贴板，也不在启动时扫描其内容。

复制操作只复制当前有效结果或用户选区。不可见字符、空结果、批量分隔符和二进制格式都有明确语义。失败保留输入、清除旧结果，成功反馈不包含完整敏感值。

## 文件权限

使用系统打开/保存面板和拖放授权访问文件。需要持续访问时采用与分发模式相适应的授权保存机制，并向用户说明范围。避免为了单个导入功能申请整个磁盘访问。

文件型工具在处理前检查大小和类型；流式任务逐步读取。图片与压缩内容同时约束解码后的体积，不能只检查压缩文件大小。

## 网络工具

请求目标、方法、请求头和请求体应在执行前可见。自动重定向、凭证转发、请求超时和代理规则必须有固定行为；跨主机重定向不能无提示地携带原 Authorization/Cookie。

证书校验默认开启。DNS 查询显示采用的解析器；WebSocket 连接有明确的断开动作。关闭会话或应用时的取消策略写入模块规格，不能遗留用户无法看到的无限连接。

数据格式工具不因为 JSON Schema、XML、Markdown、SVG 或图片里带有远程引用，就自动发起网络请求。用户主动配置的网络工具与内容预览的网络能力分开。

## 预览与复杂解析

Markdown/HTML/SVG 等预览采用受限环境，默认关闭脚本执行、外部资源和本地路径访问。JS/TS/CSS/SQL 格式化只解析文本，不执行输入代码。

cURL 导入按受支持语法静态解析，不交给 shell；未知选项明确报错，不能忽略后发送一个与原命令不同的请求。

正则匹配、深层数据解析和图片解码有时间、内存、深度与输出上限。不能可靠中断的工作放入可终止的隔离进程，具体机制由工作进程与取消回归验证。

## CLI 与 AI Skill

CLI 仅读取显式传入的文本、stdin 或文件路径，不访问应用会话或剪贴板，不保存调用历史。联网工具要求 `--allow-network`；Skill 引导 AI 根据用户已授权的目标与操作使用。敏感正文和选项建议使用 stdin JSON 或受控文件，避免进入进程参数、Shell 历史和日志。附件在默认排版中仅显示名称、类型与大小；JSON 模式提供 Base64 数据，由调用方决定是否落盘。

用户点击安装时，设置页创建当前应用 CLI / Skill 的用户目录链接；已有未知文件或链接不覆盖。CLI 安装会在 zsh / bash 启动文件追加带标记、可移除且幂等的 PATH 块，保留原有内容，不提升权限。只有安装位置保存在偏好中，输入和执行结果不写入偏好。

## Spotlight

应用不把输入或结果作为可搜索内容上传到 Core Spotlight 索引。动作描述只包含工具的名称、参数、用途等静态元数据。

通过系统 Spotlight/快捷指令输入的数据会由系统接收和调度；系统自己的历史与建议策略不能被表述为 DevKit 能完全控制。应用不主动持久化这些正文，不在后台额外读取剪贴板。

## 公开发布前

形成实际的数据流说明、隐私说明、依赖许可证清单和权限列表。App Store 与直接分发的沙箱、签名、安装及更新方式需要分别验证。文档只能描述真正采用的行为，不能先声明“绝对不会联网”或“所有数据都不会留下任何记录”。
