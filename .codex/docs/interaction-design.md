# 交互约束

## 导航与会话

主窗口通过分类、搜索和收藏选择工具，不展示工具标签栏。切换工具保留输入、参数、结果和轻量显示状态，只挂载当前页面。重复选择当前工具不重建会话。

普通工具可打开独立输入、结果或对照窗口，共享业务会话。关闭一个窗口不影响仍被其他窗口使用的会话。WebSocket 使用专属连接界面，切换页面不应断开，关闭所属会话时释放连接。

## 输入与参数

文本、图片、文件、日期、颜色、数值、生成器按场景选择控件。表单标签统一对齐；密钥使用安全输入框，时区提供搜索和选择，影响结果的参数必须可见或能明确找到。

编辑器参数位于两侧面板上方，最多两行，宽度不足时溢出到“更多”。排列依据标签和控件宽度，不因输入值长度或运行状态跳动；溢出参数保持绑定并支持恢复默认。

主操作位于工具栏，名称匹配当前动作，例如“格式化”“校验文件”“验证签名”。运行中可取消。输入区提供示例、粘贴、导入和清空，避免重复执行按钮。

## 结果与错误

结果支持文本、条目、预览和文件视图。状态位于面板内固定区域，不因状态出现改变整体高度。验证与对比工具提供摘要、统计和明细。

输入或参数变化时，旧结果显示待更新并禁止作为当前结果复制。执行失败清除旧结果；导入失败必须阻止误执行旧输入，并提供明确恢复路径。复制和导出使用完整数据。

大文本按段编辑和查看，保留全文；页面切换、撤销边界和超长行横向滚动需要清晰提示。新结果应重置不适用的滚动和选区。编辑器的原生更新不能反向触发业务编辑回调。

## 焦点与辅助功能

快捷键由当前原生窗口路由。主窗口、独立窗口和 AppKit 编辑器获得焦点时都应保持正确的执行、复制、搜索和面板切换目标。

图标按钮提供标签和帮助，选中状态不能仅靠颜色表达。错误信息可阅读和复制，控件支持键盘及 VoiceOver。缩放字体、窄窗口、减少动态效果下应保留主要操作。

具体使用行为和快捷键见[行为参考](user-guide.md)。
