# 快捷键与外观

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘⌥F` | 聚焦工具搜索 |
| `⌘Return` | 执行当前工具；运行时取消 |
| `⌘⌥1` / `⌘⌥2` | 切换完整输入 / 结果面板 |
| `⌘⇧C` | 复制当前有效完整结果 |
| `⌘F` | 在当前编辑器中查找 |
| `⌃⌘S` | 显示或隐藏侧栏 |
| `⌘W` | 关闭当前窗口 |
| `⌘,` | 打开设置 |

`⌘` 是 Command，`⌥` 是 Option，`⌃` 是 Control，`⇧` 是 Shift。窗口中的快捷键作用于当前获得焦点的工具或面板。

## 通用设置

打开「设置 → 通用」，选择浅色、深色或跟随系统，也可以调整编辑器字号和自动换行。

![通用设置中的外观、字号与自动换行](/images/general-settings.png)

主题作用于主窗口、设置和独立窗口。选择「跟随系统」会立即恢复当前系统外观。Liquid Glass 随系统的外观和辅助功能设置变化；启用「减少透明度」时使用不透明背景。

较长单行在关闭自动换行后可横向滚动。若需要更宽的编辑空间，切换到完整「输入」或「结果」面板，或打开独立窗口。
