# 数字格式

Decimal 十进制舍入与千分位，最多 38 位有效数字。

类别：时间与数值 · CLI ID：`number-format` · 本机处理

## 怎么用

输入十进制数字，设置小数位、舍入方式和分组符后执行。需要精确小数时，先核对输入和舍入规则。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
1234567.895
```

默认配置下的结果：

```text
1,234,567.90
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `scale` | 小数位 | `2` | 0–20 |
| `rounding` | 舍入方式 | `plain` | `plain`、`bankers`、`down`、`up` |
| `grouping` | 千分位 | `true` | `true` / `false` |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe number-format
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run number-format --input-file ./input.txt
```

## 边界与注意事项

Decimal，38 位有效数字，舍入/分组；暂不输出科学计数法。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
