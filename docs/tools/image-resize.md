# 图片尺寸

缩放或居中裁剪到目标尺寸；PNG 导出。

类别：代码与图形 · CLI ID：`image-resize` · 本机处理

## 怎么用

载入图片并填写目标宽高，选择等比缩放、透明画布或居中裁剪后执行。预览确认边界与裁切，导出 PNG。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 准备样例

选择一份可以公开的PNG 或 JPEG 图片，先用较小尺寸验证结果，再处理自己的原图。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `width` | 宽 px | `800` | 1–10000 |
| `height` | 高 px | `600` | 1–10000 |
| `mode` | 方式 | `scale` | `scale`、`fit`、`fill` |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe image-resize
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run image-resize --file ./image.png
```

## 边界与注意事项

默认等比缩放到宽高边界内，可选透明画布或居中裁剪；PNG 输出；批量队列未实现。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
