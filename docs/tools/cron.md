# Cron

五字段 Cron，预览后续执行时间，不注册系统任务。

类别：时间与数值 · CLI ID：`cron` · 本机处理

## 怎么用

输入五字段 Cron 表达式，选择时区、起点和结果数量。可以使用当前时间或指定起点，执行后查看后续时间及每次的 UTC 偏移。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
*/15 9-18 * * 1-5
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `timezone` | 时区 | `系统当前时区` | 文本 |
| `start` | 起始时间 | 空 | 文本 |
| `count` | 预览次数 | `10` | 1–100 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe cron
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run cron --input-file ./input.txt
```

## 边界与注意事项

五字段，时区、固定起点、后续时间；不创建系统计划。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
