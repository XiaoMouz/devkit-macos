# Cron

根据五字段 Cron 表达式查询后续执行时间。

CLI：`cron`

## 使用方法

输入五字段 Cron 表达式，选择时区、起点和结果数量。可以使用当前时间或指定起点，执行后查看后续时间及每次的 UTC 偏移。

## 示例

输入：

```text
*/15 9-18 * * 1-5
```

## 参数参考

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `timezone` | 时区 | `系统当前时区` | 文本 |
| `start` | 起始时间 | 空 | 文本 |
| `count` | 预览次数 | `10` | 1–100 |

## CLI 调用

```sh
devkit describe cron
```

从文件读取：

```sh
devkit run cron --input-file ./input.txt
```

## 注意事项

使用五字段表达式，不支持秒字段。结果会标注时区偏移；该工具用于查询时间，不创建定时任务。
