# 网站图标

从图片生成常用 PNG 尺寸与 ICO；原文件不覆盖。

类别：代码与图形 · CLI ID：`favicon` · 本机处理

## 怎么用

载入图标原图并生成，查看各尺寸 PNG 与 ICO。可逐项导出，或一次导出到独立文件夹。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 准备样例

选择一份可以公开的PNG 或 JPEG 图片，先用较小尺寸验证结果，再处理自己的原图。

## 参数参考

此工具无需额外算法参数，使用输入内容即可执行。

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe favicon
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run favicon --file ./image.png
```

## 边界与注意事项

PNG 尺寸集与 ICO，单项导出或全部导出到独立文件夹；不生成 ZIP。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
