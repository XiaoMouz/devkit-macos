# ULID

Crockford Base32，48 位毫秒时间戳与 80 位安全随机数。

类别：标识与测试数据 · CLI ID：`ulid` · 本机处理

## 怎么用

生成模式只需设置数量。解析模式填写已有 ULID，可查看其中的时间；生成结果每次不同。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 结果示例

生成结果每次不同。先把数量设为 1，确认格式符合需要，再增加数量。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `operation` | 操作 | `generate` | `generate`、`parse` |
| `count` | 数量 | `5` | 1–1000 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe ulid
```

生成一个结果：

```sh
devkit run ulid --text '' --option count=1
```

## 边界与注意事项

生成和时间解析；同毫秒独立随机，不提供单调工厂。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
