# DNS 查询

调用系统 dig；A / AAAA / CNAME / MX / TXT / NS，手动执行。

类别：Web 与网络 · CLI ID：`dns` · 主动执行时联网

## 怎么用

输入域名、选择记录类型。解析器留空使用系统设置，或指定解析器 IP 与端口；执行后查看服务器、答案和耗时。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `record` | 记录类型 | `A` | `A`、`AAAA`、`CNAME`、`MX`、`TXT`、`NS`、`SOA`、`CAA` |
| `resolver` | 解析器 IP（空为系统） | 空 | 文本 |
| `port` | 解析器端口 | `53` | 1–65535 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe dns
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run dns --input-file ./input.txt --allow-network
```

## 边界与注意事项

系统 dig，八类记录，自定义解析器 IP/端口，3 秒单次超时。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
