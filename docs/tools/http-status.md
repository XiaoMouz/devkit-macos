# HTTP 状态码

本地查询 HTTP 状态含义；不发送请求。

类别：Web 与网络 · CLI ID：`http-status` · 本机处理

## 怎么用

输入状态码，例如 404，执行后查看名称和说明。未收录的状态会提供 IANA 参考入口。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
404
```

默认配置下的结果：

```text
404 · Not Found
未找到资源
```

## 参数参考

此工具无需额外算法参数，使用输入内容即可执行。

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe http-status
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run http-status --input-file ./input.txt
```

## 边界与注意事项

常见状态使用明确英文名称与中文说明；未收录状态指向 IANA。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
