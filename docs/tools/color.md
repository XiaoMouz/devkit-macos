# 颜色转换

sRGB HEX / RGB / HSL 与透明度，结果点一下复制。

类别：前端样式 · CLI ID：`color` · 本机处理

## 怎么用

输入颜色值或使用颜色选择器，执行后查看 sRGB 的 HEX、RGB、HSL 和透明度表示，可逐项复制。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
#3478f6
```

默认配置下的结果：

```text
#3478F6
rgb(52 120 246 / 1)
hsl(218.97 91.51% 58.43% / 1)
```

## 参数参考

此工具无需额外算法参数，使用输入内容即可执行。

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe color
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run color --input-file ./input.txt
```

## 边界与注意事项

sRGB HEX/RGB/HSL/透明度；逐格式复制；未实现色板保存。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
