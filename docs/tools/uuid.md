# UUID

RFC 9562 UUID v4 / v7，支持批量与大小写。

类别：标识与测试数据 · CLI ID：`uuid` · 本机处理

## 怎么用

选择 v4 或 v7，设置数量、大小写和连字符，点击生成。v4 为随机 UUID，v7 带时间排序信息。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 结果示例

生成结果每次不同。先把数量设为 1，确认格式符合需要，再增加数量。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `version` | 版本 | `v4` | `v4`、`v7` |
| `count` | 数量 | `5` | 1–1000 |
| `uppercase` | 大写 | `false` | `true` / `false` |
| `hyphens` | 保留连字符 | `true` | `true` / `false` |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe uuid
```

生成一个结果：

```sh
devkit run uuid --text '' --option count=1
```

## 边界与注意事项

RFC 9562 v4/v7；v7 同毫秒不保证单调性。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
