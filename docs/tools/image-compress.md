# 图片压缩

JPEG 有损质量与目标大小；原文件不覆盖。

类别：代码与图形 · CLI ID：`image-compress` · 本机处理

## 怎么用

载入图片，设置 JPEG 质量和可选目标体积后压缩。查看实际大小；无法达到目标体积时根据提示调整尺寸或质量。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 准备样例

选择一份可以公开的PNG 或 JPEG 图片，先用较小尺寸验证结果，再处理自己的原图。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `quality` | 质量上限 % | `85` | 10–100 |
| `targetKB` | 目标 KB（0 为不限） | `0` | 0–32000 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe image-compress
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run image-compress --file ./image.png
```

## 边界与注意事项

JPEG 有损质量与目标体积；明确提示不能达标；不宣称 PNG 无损优化。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
