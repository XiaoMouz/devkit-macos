# 颜色对比度

WCAG 2.2 相对亮度对比值，普通和大号文字分开。

类别：前端样式 · CLI ID：`contrast` · 本机处理

## 怎么用

分别选择前景色和背景色，执行后读取对比度以及不同字号下的 AA / AAA 结论。当前只接受不透明颜色。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
#FFFFFF
```

默认配置下的结果：

```text
对比值: 4.0671:1
AA 普通文字 ≥4.5: 未通过
AA 大号文字 ≥3: 通过
AAA 普通文字 ≥7: 未通过
AAA 大号文字 ≥4.5: 未通过
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `background` | 背景颜色 | `#3478F6` | 文本 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe contrast
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run contrast --input-file ./input.txt
```

## 边界与注意事项

WCAG 2.2；不透明颜色，AA/AAA 条件明确。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
