# 日期与时区

日期时间选择、时区转换、日期加减与时间差。

类别：时间与数值 · CLI ID：`date-time` · 本机处理

## 怎么用

选择时区转换、日期加减或时间差。分别确认输入时区和目标时区，使用日期时间选择器填写日期；时间差还需填写第二个日期。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
2026-10-11 12:00:00
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `operation` | 操作 | `zones` | `zones`、`add-days`、`difference` |
| `sourceZone` | 输入时区 | `系统当前时区` | 文本 |
| `zone` | 目标时区 | `系统当前时区` | 文本 |
| `days` | 增减天数 | `1` | -36500–36500 |
| `other` | 对比日期 | `当前时刻` | 文本 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe date-time
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run date-time --input-file ./input.txt
```

## 边界与注意事项

原生日期时间选择、输入/目标时区选择；日历加天和实际时间差，结果按所选时区显示。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
