# 进制转换

整数进制转换，支持大整数和负数。

CLI：`number-base`

## 使用方法

输入整数，选择来源进制和目标进制，再转换。处理大整数时直接保留字符串输入，不需要先转成小数。

## 示例

输入：

```text
255
```

结果：

```text
ff
```

## 参数参考

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `from` | 源进制 | `10` | `2`、`8`、`10`、`16` |
| `to` | 目标进制 | `16` | `2`、`8`、`10`、`16` |

## CLI 调用

```sh
devkit describe number-base
```

从文件读取：

```sh
devkit run number-base --input-file ./input.txt
```

## 注意事项

支持带符号整数，不提供固定位宽补码转换。
