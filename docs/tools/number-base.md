# 进制转换

基于大整数精确转换，支持正负数；不隐式套用补码。

类别：时间与数值 · CLI ID：`number-base` · 本机处理

## 怎么用

输入整数，选择来源进制和目标进制，再转换。处理大整数时直接保留字符串输入，不需要先转成小数。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
255
```

默认配置下的结果：

```text
ff
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `from` | 源进制 | `10` | `2`、`8`、`10`、`16` |
| `to` | 目标进制 | `16` | `2`、`8`、`10`、`16` |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe number-base
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run number-base --input-file ./input.txt
```

## 边界与注意事项

BigInt 精确进制转换，带符号；不提供固定位宽补码模式。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
