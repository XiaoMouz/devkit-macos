# Nano ID

安全随机与无偏采样，可自定义 Unicode 字符集。

类别：标识与测试数据 · CLI ID：`nanoid` · 本机处理

## 怎么用

设置长度、数量与自定义字符集后生成。字符集会影响标识符可选字符，复制结果用于自己的测试或标识场景。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 结果示例

生成结果每次不同。先把数量设为 1，确认格式符合需要，再增加数量。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `length` | 长度 | `21` | 1–4096 |
| `count` | 数量 | `5` | 1–1000 |
| `alphabet` | 字符集 | `_-0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ` | 文本 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe nanoid
```

生成一个结果：

```sh
devkit run nanoid --text '' --option count=1
```

## 边界与注意事项

安全随机与自定义字符集；总字符上限 100000。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
