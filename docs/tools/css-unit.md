# CSS 单位

px / rem / em / vw / vh，基准尺寸明确可调。

类别：前端样式 · CLI ID：`css-unit` · 本机处理

## 怎么用

输入长度，选择来源和目标单位，按需设置根字号、父字号及视口宽高。执行后核对结果所依据的上下文参数。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
24
```

默认配置下的结果：

```text
1.5rem
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `from` | 源单位 | `px` | `px`、`rem`、`em`、`vw`、`vh` |
| `to` | 目标单位 | `rem` | `px`、`rem`、`em`、`vw`、`vh` |
| `root` | 根字号 px | `16` | 1–256 |
| `parent` | 父字号 px | `16` | 1–256 |
| `width` | 视口宽度 px | `1440` | 1–20000 |
| `height` | 视口高度 px | `900` | 1–20000 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe css-unit
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run css-unit --input-file ./input.txt
```

## 边界与注意事项

px/rem/em/vw/vh；显式根字号、父字号与视口。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
