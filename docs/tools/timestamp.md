# 时间戳

Unix 秒 / 毫秒与日期时间互转，按所选时区显示。

类别：时间与数值 · CLI ID：`timestamp` · 本机处理

## 怎么用

选择秒、毫秒或日期输入，选择时区后转换。需要普通日期时使用原生日期时间选择器；切换输入模式会保留毫秒精度。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
1700000000
```

以 `Asia/Shanghai` 为时区，`1700000000` 秒对应 `2023-11-15 06:13:20`。改变时区会改变显示日期，不改变这一瞬间。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `unit` | 时间戳单位 | `seconds` | `seconds`、`milliseconds` |
| `timezone` | 时区 | `系统当前时区` | 文本 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe timestamp
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run timestamp --input-file ./input.txt
```

## 边界与注意事项

秒/毫秒与普通日期互转、时区选择、当前时间；保留毫秒精度并检查日期范围。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
