# 文本统计

区分字素、Unicode 码点、UTF-16 和 UTF-8 字节。

类别：文本与匹配 · CLI ID：`text-stats` · 本机处理

## 怎么用

输入或导入文本后执行，比较字素、码点、UTF-16、UTF-8 字节与行数。Emoji 的屏幕字符数与内部编码长度可能不同。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
Hello 世界 👩‍💻
```

默认配置下的结果：

```text
字素: 10
Unicode 码点: 12
UTF-16 单元: 14
UTF-8 字节: 24
行: 1
词（空白分隔）: 3
```

## 参数参考

此工具无需额外算法参数，使用输入内容即可执行。

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe text-stats
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run text-stats --input-file ./input.txt
```

## 边界与注意事项

字素/码点/UTF-16/字节/行；词数按空白分隔。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
