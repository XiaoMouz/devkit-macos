# 哈希摘要

MD5 / SHA 摘要；MD5 和 SHA-1 仅用于兼容与校验。

类别：摘要与令牌 · CLI ID：`hash` · 本机处理

## 怎么用

输入要计算摘要的文本，选择算法与十六进制大小写，点击“计算摘要”。换行和前后空格都会参与计算。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 试一个例子

下面使用公开演示数据。输入内容：

```text
hello
```

默认配置下的结果：

```text
2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
```

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `algorithm` | 算法 | `SHA-256` | `MD5`、`SHA-1`、`SHA-256`、`SHA-512` |
| `uppercase` | 大写 | `false` | `true` / `false` |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe hash
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run hash --input-file ./input.txt
```

## 边界与注意事项

MD5/SHA-1/SHA-256/SHA-512；旧算法标识为兼容用途。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
