# 图片信息

查看尺寸、EXIF 与色彩信息；可导出移除元数据的新 PNG。

类别：代码与图形 · CLI ID：`image-metadata` · 本机处理

## 怎么用

载入图片后查看元数据。需要清理时开启移除选项并重新执行，导出重新编码的图片。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 准备样例

选择一份可以公开的PNG 或 JPEG 图片，先用较小尺寸验证结果，再处理自己的原图。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `strip` | 导出移除元数据的 PNG | `false` | `true` / `false` |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe image-metadata
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run image-metadata --file ./image.png
```

## 边界与注意事项

信息查看和重新编码移除元数据；尚无逐字段选择性删除。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
