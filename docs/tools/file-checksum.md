# 文件校验

计算文件摘要，并与期望值比较；支持取消。

类别：摘要与令牌 · CLI ID：`file-checksum` · 本机处理

## 怎么用

选择文件并设置摘要算法，点击计算。需要核对下载文件时，把发布者提供的摘要填入预期值；结果会同时展示摘要与比较状态。大文件运行中可取消。

运行完成后，从结果面板复制或导出。修改输入或参数后需要重新执行。

## 准备样例

选择一份可以公开的本地文件。

## 参数参考

下表列出参数 ID，便于 CLI / AI 调用；界面只显示当前操作需要的参数。时区和当前时刻等默认值会随系统变化。

| 参数 | 名称 | 默认值 | 可选值或范围 |
| --- | --- | --- | --- |
| `algorithm` | 算法 | `SHA-256` | `MD5`、`SHA-1`、`SHA-256`、`SHA-512` |
| `expected` | 期望摘要（可选） | 空 | 文本 |

## CLI 调用

先在「设置 → CLI 与 AI」安装命令。查看参数：

```sh
devkit describe file-checksum
```

将示例输入保存为相应文件后执行；示例文件名需换成你的实际文件：

```sh
devkit run file-checksum --file ./download.zip
```

## 边界与注意事项

原生选取文件使用流式摘要和比较，无 32 MiB 整体读入限制；显示读取进度并支持取消。

应用内原生文件选择使用流式校验；上面的 CLI 文件调用仍限制为 32 MiB。

常规文本输入合计上限 5 MiB；普通文件输入上限 32 MiB，具体工具可能更低。详情见[文件与导出](../files.md)。
