# 隐私与数据边界

## 本机处理

文本、编码、JSON、摘要和图片处理在本机完成。正文和密钥默认不跨启动保存；工具输入、参数和结果保存在当前内存会话。收藏、外观与工具开关等偏好会被保存。

DevKit 不会因你输入内容而自动执行转换。复制、粘贴、文件导入和网络请求都由你的操作触发。

## 哪些工具联网

HTTP、WebSocket、DNS 只有主动执行或连接时联网。CLI 使用这些工具必须加 `--allow-network`。URL 解析、Cookie、cURL 转换在本机解析内容，不会自动访问其中的地址。

Markdown、SVG 和 CSS 预览禁止脚本和外部资源，不会因预览而访问输入中引用的网站。代码格式化和压缩不执行粘贴进去的程序。

## 令牌和密钥

JWT 解码、验签和时间有效性是不同结论。当前仅支持 HS256 验签，不判断业务上的 `aud` / `iss` 可信度。PEM 与证书工具显示证书信息，不验证信任链，不解析私钥。

在终端处理正文、令牌或密钥时，用 stdin 或受控文件传入，避免把它们写进 Shell 历史或进程参数。导出文件由你选择位置和访问权限；分享截图、结果或问题报告前应移除真实凭据。

## 执行与大小限制

大部分工具通过独立工作进程执行，支持取消和超时。进程隔离不是操作系统安全沙箱，也不代表严格内存硬上限。文本、文件和输出分别有大小限制，详见[文件与导出](files.md)及各工具页面。

## 文档站

手册使用静态页面和浏览器内搜索，不接收工具输入，也没有在线执行开发工具的表单。阅读文档不需要登录。网站托管在 GitHub Pages，访问请求由 GitHub 处理。
