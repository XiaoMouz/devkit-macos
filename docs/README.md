版本：实现预览 0.1.0，保留设计基线。更新日期：2026 年 10 月 9 日。目标系统：macOS 26 及以上。

## 当前基线

已确认：完整工具箱为主体；广泛覆盖 Web 日常工具；一个功能一个模块目录；苹果原生视觉与高效操作；采用 Liquid Glass；跟随系统界面；macOS 26+；先自用、后公开发布。

Spotlight 同时要求命令式 B 和引导式 A，B 优先验证。用户接受首次设置关键词，执行后点击结果复制。搜索后仅打开主窗口，不满足这项要求。

工具清单、分批顺序、尺寸、默认参数、技术分层和性能目标是本轮设计建议。Spotlight 的完整命令能否原样传入、关键词约束和 A/B 共存方式，仍是系统验证项。

## 使用方式

用户于 2026-10-09 明确要求开始写代码，项目已进入实现阶段。使用、实际能力与检查结果分别维护在新增文档中。

原始设计与验收计划保留为目标；48 个模块已有实现，但不表示所有高级选项、系统入口或发布条件已通过。不能用动作注册替代真实 Spotlight 验收。

文档按主题维护，避免将整个项目说明堆入一个文件。新增工具时先更新工具目录与该工具规格，再修改实现及对应验收记录。
