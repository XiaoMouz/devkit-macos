# DevKit 工具目录

共规划 9 类、72 个模块。每行对应一个独立功能目录；同一工具的编码/解码或多个算法作为内部操作，不拆成重复页面。本表保留原始设计范围；当前 72 个模块都有实现，各项子能力的实际范围与限制见 [实现记录](implementation-status.md)。

批次 1 为核心日用工具，批次 2 为开发数据工具，批次 3 为前端与资源工具，批次 4 为复杂格式及网络工具。批次说明见 [交付计划](delivery-plan.md)。

“快捷候选”表示适合接入 Spotlight A，以及在 B 可行性通过后接入命令模式；它不是已经获得系统支持的结论。“工具箱”表示以主窗口交付。所有工具都有独立输入、参数、错误、资源限制和测试，具体规则按 [模块规范](module-specification.md) 展开。

## 扩展规则

新工具先说明使用场景、与已有工具的区别、输入输出和维护成本，再按统一模块模板加入。本目录作为唯一功能清单；模块状态、测试和说明必须可追踪到对应 ID。

初版依赖已选型，见 [开发维护](development.md)；后续扩展格式仍需独立评估。实施对应批次前核实规范版本、维护状况、许可证、体积和沙箱支持；清单中的格式范围不能直接当作底层系统 API 已全部支持。
