# Spotlight

Spotlight 集成默认关闭。它提供在系统搜索中调用工具的入口，但 v0.1.0 的完整命令、参数卡片、复制和焦点行为仍需进一步系统验证。主窗口和 CLI 可独立使用。

## 启用工具

1. 打开「设置 → Spotlight」。
2. 打开启用总开关，再开启需要的工具。
3. 按页面引导在系统 Spotlight 绑定快捷短语。

![Spotlight 设置中的工具开关与快捷短语说明](/images/spotlight-settings.png)

系统动作需要有效的开发者签名。索引同步成功只说明工具信息已写入，不等于系统已成功执行，也不会自动设置 Quick Key。

## Base64 首次绑定

1. 按 `⌘Space` 打开 Spotlight，再按 `⌘3` 进入操作列表。
2. 搜索 **Base64 命令**，确认来源为 DevKit。
3. 点击动作旁的「添加快捷短语」，填写 `base64`。
4. 之后尝试 `base64 encode 123`，预期结果为 `MTIz`；`base64 decode MTIz` 则还原 `123`。

不设置快捷短语时，也可以先选择「Base64 命令」，在命令栏输入 `encode 123`。希望逐步选择操作时，搜索「Base64 编码或解码」。

如果只看到「搜索网页」或「搜索 iCloud 云盘」，说明还在普通搜索，没有进入 DevKit 动作。系统提示里的“快捷指令”是动作框架名称，不要求自己在快捷指令 App 编排工作流。

## 通用入口与别名

选择「DevKit 命令」，输入完整工具命令；也可以给这个动作设置 `dk` 快捷短语。引导式入口叫「DevKit 工具操作」。

应用内别名以逗号分隔，不得与其他工具冲突；它不会更改系统快捷短语，原工具 ID 始终可用。下面的 `b64` 需要先配置为 Base64 的应用内别名：

```text
b64 encode hello
base64 dec aGVsbG8=
uuid 3
hash MD5 hello
```

`b64 encode --` 表示空文本；`b64 encode --  hello` 会保留 `hello` 前的一个空格。含空白的输入应按该命令入口的约定填写。

## 关闭和排查

关闭工具会移除对应工具索引并阻止执行，系统可能仍显示已注册动作名称。「清空索引并关闭」只影响 DevKit。若系统卡片没有出现，先确认签名、工具开关和动作入口，再尝试重新同步；可先回主窗口执行相同操作确认输入本身有效。

系统快捷短语操作见 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mchl4953dfeb/26/mac/26)。
