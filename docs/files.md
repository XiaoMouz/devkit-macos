# 文件与导出

## 选择正确的输入方式

| 内容 | 操作 |
| --- | --- |
| UTF-8 文本、JSON、代码 | 输入面板「导入」，或拖入文本文件 |
| 图片 | 「选择图片」、拖入图片，或粘贴图片 |
| 文件摘要 | 文件校验中的「选择文件」 |
| 一段文本 | 直接输入，或点击「粘贴」 |

Base64 处理 UTF-8 文本；图片编解码使用 [Data URL](tools/data-url.md)。

## 文件大小

文本输入合计上限 5 MiB，普通图片和二进制文件上限 32 MiB。图片还受像素尺寸限制。

应用内「文件校验」采用流式读取，可处理超过 32 MiB 的文件，并显示进度、支持取消。CLI 的文件输入仍有 32 MiB 限制。

## 复制与导出

结果面板「复制」或 `⌘⇧C` 复制当前有效的完整结果。图片结果复制图片，文本结果复制完整文本；条目旁的复制按钮只复制该项。

「导出…」打开系统保存面板。根据工具，输出可能是文本、JSON、PNG、JPEG、ICO 或其他附件。保存前确认文件名和目标位置；应用不会直接改写原文件。

网站图标可导出某个尺寸，也可「全部导出到文件夹…」，在选定位置创建独立子文件夹。目前不生成 ZIP。

## 图片注意事项

图片处理读取首帧并修正方向。JPEG 不支持透明度，透明区域会合成为白色；需要透明背景时请选择 PNG。转换、缩放和移除元数据都可能重新编码，导出后应检查尺寸、透明度和颜色是否符合预期。

## 导出前提示待更新

输入或参数改变后，点击顶部主按钮重新执行，完成后即可复制或导出。
