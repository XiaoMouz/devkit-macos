# DevKit 交互设计

> 2026-10-10 当前实现以本段及 [UI 修正记录](ui-refinement.md) 的最新记录为准。顶部与左侧为同一透明外壳，右侧为整块无边框工作区；移除底栏与贯穿横线。操作、输入/结果/对照切换以及复制、清空、导出、独立窗口均在顶部。配置在右侧独立滚动，可收起。保留收藏，不设常用区或工具标签页。下文早期草案中的标签与参数弹层不再代表当前方案。


本设计以完整工具箱为日常工作空间，Spotlight 为轻量入口。以下布局、快捷键及默认行为是设计建议，视觉细节在静态设计评审中收敛。

## 信息架构

窗口由系统标题栏与工具栏、可收起侧栏、工具标签页、工作区和可选参数检查器组成。侧栏包含搜索、收藏和九类工具。按用户后续要求移除“最近使用 / 常用”；收藏项不在分类中重复展示，搜索时搜索全部工具。

工具多时优先改善检索：中文名、英文名、常见别名和用途都可命中；例如搜索“base64”“b64”“编码”可找到相关工具。结果展示工具名称、类别和简短用途，键盘上下选择、回车打开。

首页展示分类和搜索入口，不为 72 个工具铺满大型卡片。首次没有收藏时提供核心工具建议，不能伪造使用记录。

## 标签页与会话

普通点击侧栏工具，优先激活已有同类标签；通过“在新标签页打开”创建独立实例。两个 Base64 标签互不覆盖输入和参数。切换标签保留当前内存会话。

关闭窗口后保留应用的标准后台生命周期由原型验证决定，但不以常驻大窗口保证 Spotlight 能运行。重启默认可恢复工具标签标识，输入、输出、密钥、网络响应不自动落盘。

导入并修改的文件只有在用户选择保存/导出时写入。关闭带有未保存文件改动的标签使用系统式保存提醒；纯粘贴临时文本的恢复策略应在产品设置中说明。

## 四种工作区模板

| 模板 | 适合工具 | 布局 |
| --- | --- | --- |
| 输入与输出 | Base64、URL、格式化、时间戳 | 顶部操作模式；左右输入输出；可选参数检查器 |
| 配置与结果 | UUID、随机字符串、Mock 数据 | 左侧紧凑配置；右侧结果列表或预览 |
| 编辑与预览 | Markdown、CSS、SVG、图片 | 编辑/参数与预览分区，预览区域可调整 |
| 调试与详情 | HTTP、WebSocket、证书 | 请求配置、响应/消息、详情分栏，明确开始/停止操作 |

文本对比使用专用的左右对齐视图，复用编辑器能力而非硬套通用转换页面。参数少时留在顶部；参数多时放入可折叠检查器。复制、执行等高频操作不藏入检查器。

## 编辑与处理

纯文本编辑禁止智能引号、自动纠错、自动替换和富文本注入。支持标准撤销/重做、选区、查找、行号、软换行、字符/字节统计；有语法的工具按需增加高亮和错误定位。

默认保留用户输入，运行失败也不清空。结果状态为：未执行、执行中、成功、失败、待更新、已取消。成功后修改输入或参数，旧结果保留供对照，但标记“待更新”，禁用“复制当前结果”和“结果作为输入”，防止把旧输出当成新输出。

执行中可以取消。新的请求替代旧请求后，任何旧任务的成功或失败都不能再更新当前页面。生成器不因渲染、切换标签、调整窗口或打开结果卡片而重新生成。

“结果作为输入”只修改当前工具会话。编解码工具同时切换方向，其他工具不猜测反向操作。原输入应可通过撤销恢复。

轻量确定性操作可以提供“自动转换”开关。对大文本、随机生成、联网和写入文件，该开关无效或不提供；不能让每次按键触发联网或不断产生新随机值。

## 复制与导出

用户已确认 Spotlight 结果点一下就复制，复制由明确点击触发，不在执行成功时自动覆盖剪贴板。

| 场景 | 交互 |
| --- | --- |
| Spotlight 短结果 | 结果主卡片作为复制操作区；点击复制完整结果；同位置反馈“已复制” |
| 主窗口短结果单元 | 点击结果或复制图标复制；悬停提示复制内容范围 |
| 主窗口文本编辑区 | 保留文本选择行为；选区用系统复制，完整结果用明显的“复制结果”操作 |
| 生成列表 | 行级复制和“复制全部”同时提供；保持生成顺序 |
| 长结果预览 | 可截断展示，但必须注明；复制和导出取完整值 |
| 二进制/图片 | 明确“复制图片”“导出文件”；不能假装为可复制的 UTF-8 文本 |

反馈不弹模态框、不移动键盘焦点；辅助功能能读出复制成功或失败。连续点击同一结果应稳定。失败后保留原结果并允许重试。

## 文件与批量任务

支持在相关工具拖入文件，文件不适用时提示接受的类型。读入前检查文件类型和大小；进入批量任务后逐项显示成功、失败、取消，单项失败不隐藏其他项目结果。

导出使用系统保存面板，默认生成新文件。重复文件名、覆盖、部分失败和取消都要有确定行为。大文件由流式处理、后台任务或独立工作进程承担，不能在主线程整文件展开。

## 搜索与键盘

主窗口建议采用以下快捷键，正式实现前检查与系统及编辑器菜单的冲突。所有快捷键都在菜单中可发现，禁用条件一致。

| 快捷键 | 行为 |
| --- | --- |
| ⌘⌥F | 聚焦工具搜索 |
| ⌘F | 查找当前编辑器文本 |
| ⌘Return | 执行当前工具的主操作 |
| ⌘⇧C | 复制当前有效的完整结果 |
| ⌘T | 选择工具并新建标签 |
| ⌘W | 关闭当前标签；最后一个标签按窗口规则处理 |
| ⌘1…⌘9 | 切换标签，不固定绑定 72 个工具 |
| ⌘, | 打开设置 |
| Escape | 关闭临时弹层；存在可取消任务时提供清晰的取消入口 |

Spotlight 的按键由系统提供，不能直接把主窗口快捷键宣称为系统结果卡片能力。

## 空态与错误

空态给出可用示例和下一步操作。有效的空文本结果与“尚未执行”不同，显示 0 字节并允许按该工具规则复制。

语法错误展示行列或字节位置；格式不支持时列出可支持的格式；网络错误区分地址、连接、TLS、超时与服务端响应；权限错误给出重新选择文件的入口。错误提示不复述完整的密码、令牌或请求头。

## 设置范围

建议分为通用、外观、编辑器、工具默认值、Spotlight、数据与文件、关于。外观默认跟随系统；收藏和常用参数可持久化；历史记录默认关闭。

Spotlight 页面介绍 A/B 入口、首次关键词配置、支持的动作和验证状态。只有通过实机验证的操作才展示“可用”，不能仅凭构建含有元数据就展示系统搜索已经就绪。
