# 工作区与多窗口

工作区由侧栏、顶部工具栏、输入和结果组成。不同工具会使用文本编辑器、日期/数值表单、文件选择器或专属网络界面。

![JSON 输入与结果并排显示](/images/json-workspace.png)

## 输入、参数、执行

输入区的「示例」「粘贴」「导入」分别用于体验、读取剪贴板和载入文件。清空按钮只清理对应输入。参数放在输入旁，只显示当前操作相关的字段。

顶部主按钮随操作变化，例如「格式化」「计算摘要」「校验 Schema」。按 `⌘Return` 也可执行；运行期间使用取消操作，避免继续处理不再需要的任务。修改输入或参数不会自动运行。

## 对照与完整面板

| 布局 | 用途 |
| --- | --- |
| 对照 | 同时编辑输入、查看结果 |
| 输入 | 把空间留给长文本或多参数输入 |
| 结果 | 阅读长输出、图片或校验报告 |
| 自动布局 | 根据内容大小和窗口宽度选择合适的显示方式 |

通过工具栏选择「输入 / 结果 / 对照」，在「窗口与布局」菜单中调整自动布局。手动选择的布局不会因为继续输入而反复切换。结构对比、Schema 等需要两份内容的工具会提供第二输入入口。

## 读懂结果

「未执行」「成功但内容为空」「失败」「待更新」代表不同状态。修改输入后，旧结果会失效，不能当作新结果复制或导出。

文本、条目、预览、折叠视图等可通过结果面板的视图菜单切换。校验和对比结果还有摘要、数量与明细。HTTP 请求完成不等于状态码成功，JWT 解码成功不等于验签通过；应继续查看结果的具体状态。

## 独立窗口

在「窗口与布局」菜单中打开输入、结果或对照窗口。独立窗口与来源工具共享同一份内存会话：修改输入会让所有关联窗口的结果一起变为「待更新」。

切换主窗口里的工具，不会改变已经打开的独立窗口；关闭主窗口后，独立窗口仍可继续使用。重复打开同一面板会激活已有窗口。关闭该会话的最后一个窗口后，其内容不再保留。

WebSocket 使用专属连接界面，不套用普通转换工具的多窗口流程。

## 大文本

超过 131072 个 UTF-16 单元的文本按段编辑，每段约 32768 个单元。使用「上一段 / 下一段」切换，「复制全文」取得完整内容。计算、导出与复制仍使用全文。

分段使用纯文本显示；切段时当前段的撤销记录会清理。超长单行可以横向滚动。默认文本总上限为 5 MiB，工具可能有更低限制。需要修改已加载内容时，先确认自己在正确的分段内。
