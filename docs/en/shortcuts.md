# Shortcuts, language & appearance

## Common shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘⌥F` | Focus tool search |
| `⌘Return` | Run the current tool, or cancel while running |
| `⌘⌥1` / `⌘⌥2` | Show the full input / result panel |
| `⌘⇧C` | Copy the current valid full result |
| `⌘F` | Find in the current editor |
| `⌃⌘S` | Show or hide the sidebar |
| `⌘W` | Close the current window |
| `⌘,` | Open Settings |

`⌘` is Command, `⌥` is Option, `⌃` is Control, and `⇧` is Shift. Window shortcuts apply to the currently focused tool or panel.

## Choose a language

In **Settings → General**, choose the system language, English, or Simplified Chinese. The interface, menus, and status labels update immediately without quitting. Input, options, results, and operations in progress remain intact.

Existing results and errors retain their content. Running tasks use the language selected when they started; subsequent runs use the new language. Some macOS dialogs and Spotlight text update the next time the system loads them. Changing language does not rewrite input text, code, or command parameters.

This guide uses English names. App screenshots currently show the Chinese interface; controls have the same positions in both languages. The documentation language can be changed independently using the menu at the top of this site.

## General settings

Open **Settings → General** to choose light, dark, or system appearance, adjust the editor font size, and set line wrapping.

![Appearance, font size, and line wrapping in General settings; screenshot shown in Chinese](/images/general-settings.png)

The theme applies to the main window, Settings, and separate windows. Choosing the system setting immediately restores the current macOS appearance. Liquid Glass follows system appearance and accessibility settings; Reduce Transparency uses an opaque background.

Long lines scroll horizontally when wrapping is off. For more editing space, switch to the full input or result panel, or open a separate window.
