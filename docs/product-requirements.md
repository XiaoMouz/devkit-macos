# DevKit 产品需求

## 产品定位

为 Web 开发者提供可长期使用的原生 macOS 工具箱，把经常需要在在线网站、终端脚本和零散应用间完成的操作集中到一个工作空间。优先保证结果正确、操作直接、界面符合系统习惯，以及功能持续增加后的可维护性。

完整工具箱是产品主体。Spotlight 用于快速处理短文本或生成简单结果；两种入口共享处理规则，不各自实现一套算法。

## 已确认的要求

| 主题 | 要求 |
| --- | --- |
| 用户 | 先供自己使用，后续计划公开发布 |
| 系统 | macOS 26 及以上 |
| 功能广度 | 广泛覆盖 Web 开发常用工具，持续扩展 |
| 维护方式 | 一个工具一个独立目录，避免多个功能挤在一个大文件中 |
| 视觉 | 苹果原生应用风格，使用 Liquid Glass，尽量适配系统 UI |
| 操作 | 兼顾开发者的键盘效率、输入输出对照和批量工作 |
| Spotlight B | 优先探索 `base64 encode hello` 这种整行命令，直接显示结果 |
| Spotlight A | 搜索 `base64`，选择编码或解码，输入文本后执行并显示结果 |
| 首次配置 | 接受用户第一次手动设置 Spotlight 关键词 |
| 复制 | 不自动覆盖剪贴板；结果出现后点一下即可复制 |
| 工作顺序 | 先完成讨论及文档，再进入项目开发 |

## 核心使用场景

1. 在工具箱找到 JSON 工具，粘贴较长响应，格式化并定位错误；切换工具后回来，当前会话内容仍在。
2. 批量生成 UUID 或测试数据，查看单条结果，按需复制单条或完整输出。
3. 比较两份文本、验证正则、调试颜色或处理图片，同时保留多个工具标签页。
4. 从 Spotlight 输入 Base64 命令，执行后直接查看结果并点击复制，不切换到主窗口。
5. 临时不知道命令语法时，在 Spotlight 选择具体动作并按提示填写参数。
6. 在明确选择网络工具后，主动发送一次 HTTP 请求或 DNS 查询，清楚知道目标地址和请求内容。

## 功能范围

当前工具范围为 [工具目录](tool-catalog.md) 中的 48 个模块，已按 2026-10-10 用户要求从原 72 个模块精简；移除原因见目录。新增或替代功能需说明实际使用场景。

工具箱公共能力包括分类、搜索、收藏、标签页、独立会话、拖入文件、复制、导出、设置、快捷键和帮助。首次打开不列出大量空页面；只展示已经可用的功能。

主窗口承载所有已交付工具。Spotlight 只接入适合短输入、快速确定性执行、短结果展示的能力，不要求为每个复杂工具创建动作。

## 产品行为原则

- 输入文本保持原样。空格、换行、大小写、Unicode 字符及 JSON 数值精度都不能因方便展示而悄悄改变。
- 编码、解码、摘要、签名验证使用准确名称。Base64 不表述为安全加密；JWT 解码不表述为验签通过。
- 运行参数明确可见。影响结果的默认值要能在工具说明中找到。
- 编辑输入或参数后，旧结果标为“待更新”并停止作为当前结果复制；异步旧任务不能覆盖新结果。
- 可预览的确定性轻量操作可以支持自动更新；随机生成、联网、写文件必须由明确操作触发。
- 错误显示原因、位置及修正方式，不静默忽略不认识的字符或丢弃数据。
- 成功反馈短暂且不抢焦点。复制失败应保留结果并允许重试。

## 建议默认值

以下为草案建议，并非新增的用户确认：界面初始为中文，全部文案可本地化；外观跟随系统；不强制注册账号；无广告；不默认开启数据历史记录或后台联网；默认只保存偏好和收藏，不再记录最近使用的工具。

小文本工具可在设置中开启自动转换；初始保留显式“执行”以减少误操作。文本编辑支持标准撤销重做。标签页默认保留当前运行会话，重启后恢复工具标签但不自动恢复输入内容。

## 范围边界

工具全集围绕开发辅助，不在当前计划内扩展为完整 IDE、浏览器、数据库管理平台、团队 API 协作平台或任意脚本执行器。账号同步、收费、插件市场和云端 AI 处理留待公开发布规划；它们不是工具箱基本功能的前置条件。

是否开源、公开发布渠道和商业模式尚未确认。设计需支持后续发布，但不提前加入登录、付费或许可证界面。

## 完成判断

完成一个工具需要可用界面、正确处理、边界错误、测试、模块文档和实际交互验收。完整项目的完成进度按已验收模块记录。

Spotlight 必须在系统 Spotlight 中完成搜索、输入、执行、显示和复制；主窗口、单元测试或快捷指令目录中的表现只能算辅助证据。
