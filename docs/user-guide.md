# DevKit 使用说明

## 日常工作

侧栏可按中文名称、英文 ID、类别和用途搜索。通过侧栏切换工具，顶部不再显示工具页签；各工具在当前窗口内保留本次会话的输入、参数和结果。需要同时查看时使用独立窗口。

输入文本后点击顶部执行按钮，或按 `⌘Return`。顶部“更多工具操作”中的“填入示例”会替换当前输入。编码/解码等主要操作在顶栏；“配置”展开右侧可独立滚动的参数栏，生成器也使用该配置栏。输入、结果、对照及复制、清空、导出与独立窗口入口全部在编辑区顶部，下面是无边框内容区域。

短编码和摘要结果可以点击复制；长文本使用“复制”按钮，条目列表可逐项点击。`⌘⇧C` 复制当前有效的完整结果。计算本身不会改变剪贴板。修改输入或参数后，旧结果标记“待更新”，再次执行前不能复制或导出。

部分结果默认显示“条目”或“预览”，可以在结果标题栏切回“文本”。大文本预览最多 50 万字符，复制与导出包含完整结果。尾部换行不会被移除。

默认“自动”布局：短内容在空间足够时并排；较长内容、较多行或窄窗口使用完整面板，在“输入 / 结果”之间切换。可以通过布局菜单固定为“并排对照”或“专注阅读”，手动选择不会被内容变化覆盖。两份输入的工具会提供第二输入入口。

大段粘贴、载入文件、编辑结束和执行时会重新判断内容大小；普通逐字输入不会反复改变版式。默认参考阈值为 2 KiB、24 行或 512 字符长行，较小内容才自动回到并排，避免临界值来回跳动。并排需要至少 560 pt 的内容宽度。

编辑区顶部的独立窗口菜单可以打开输入、结果或对照窗口。这些窗口共享同一份内存会话，修改输入会使所有结果标记待更新。切换到其他工具不会改变已打开的独立窗口；关闭主窗口后，独立窗口仍可继续使用；关闭最后一个窗口才结束该会话。重复打开同一面板会激活已有窗口。

此多窗口流程用于普通转换、生成、比较和文件工具；WebSocket 保留专属连接会话界面。

## 文件与预览

图片工具点击“选择文件”；其他工具可以从输入区的更多菜单选择文件，或拖入文件。文本工具读取 UTF-8 文本；二进制工具保留原始字节。当前为单文件处理，单文件上限 32 MiB。

通过结果标题栏的导出菜单保存文本、图片或二进制文件。保存使用系统面板，不自动覆盖原文件。网站图标工具提供各尺寸 PNG 与 ICO 的单独导出项。

图片处理读取首帧，修正方向标记。JPEG 将透明背景合成为白色。Markdown、SVG 和 CSS 使用无脚本、无外部资源的本地预览；不会访问输入中出现的网站。

| 快捷键 | 行为 |
| --- | --- |
| `⌘⌥F` | 聚焦工具搜索 |
| `⌘Return` | 执行；运行期间取消 |

| `⌘⇧C` | 复制当前有效的完整结果 |
| `⌘W` | 关闭当前窗口 |

## 网络工具

HTTP：输入区填写地址，第二输入填写请求体，参数区选择方法并填写请求头 JSON，例如 `{"Content-Type":"application/json"}`。只有执行才发送请求。结果“条目”显示状态和响应头，“文本”显示正文。响应读取上限 5 MiB。

WebSocket：填写 `ws://` 或 `wss://` 地址，点击连接；左侧编辑消息并手动发送，右侧逐条展示发送与接收。点击消息复制完整值。连接可手动断开，关闭标签会关闭连接。会话上限 1000 条 / 5 MiB，单条消息 1 MiB。

DNS：输入域名，选择记录类型；解析器留空使用系统默认设置。可填写解析器 IP 和端口。输出包含服务器、答案与耗时；不创建后台轮询。

## 外观

“设置 → 通用”控制浅色、深色或跟随系统，以及编辑器字号和自动换行。主题统一作用于主窗口、设置与独立窗口；选择“跟随系统”会立即恢复系统当前外观。

Liquid Glass 可选“跟随系统”或“自定义”。跟随系统时，顶部和左侧背景响应 macOS 的 Liquid Glass 设置；自定义时显示“磨砂强度”滑块，左侧 0% 为通透档、右侧 100% 为磨砂档，与系统设置方向一致。全程保留适合导航文字的原生常规玻璃，最通透档也保留基础对比度保护；只有系统开启“减少透明度”时才使用不透明背景。自定义值单独保存，切换模式不会覆盖它。侧栏与主体由系统分隔线区分；操作按钮使用原生 Glass 样式，工具操作和输入/结果/对照使用原生分段控件。

## Spotlight

默认关闭。进入“设置 → Spotlight”打开总开关和需要的工具。若页面提示临时签名，需先使用 Apple 开发证书重新构建；当前本机系统会拒绝没有开发者 Team ID 的动作调用，重复绑定无法解决。索引同步成功只表示工具信息已写入，不代表系统执行已通过，也不会替你绑定系统快捷短语。

A、B 都在系统 Spotlight 中完成；系统报错中的“快捷指令”是动作执行框架，不要求打开快捷指令 App 或自己编排工作流。

### Base64 首次绑定

1. 按 ⌘ 空格打开 Spotlight，再按 ⌘3 进入操作列表。
2. 搜索 **Base64 命令**，确认来源为 DevKit。
3. 点击该动作旁的“添加快捷短语”，设置为 `base64`。
4. 输入 `base64 encode 123` 并回车，预期结果为 `MTIz`；输入 `base64 decode MTIz`，预期结果为 `123`。

不绑定也可以直接选择“Base64 命令”，在命令参数中输入 `encode 123`。要逐步选择编码或解码，搜索 **Base64 编码或解码**。如果只出现“搜索网页”或“搜索 iCloud 云盘”，当前仍是普通搜索，尚未进入 DevKit 动作。

### 其他工具与应用内别名

在 Spotlight 选择 **DevKit 命令**，输入完整命令，或给它设置 `dk` 快捷短语后输入 `dk` 加完整命令。也可以选择 **DevKit 工具操作**，再选已启用的工具和操作。

应用内别名用逗号分隔，不允许与其他工具名或别名冲突；修改它不会改变系统快捷短语。原工具 ID 始终可用。例如：

```text
b64 encode hello                    → aGVsbG8=
base64 dec aGVsbG8=                 → hello
b64 encode --                      → 空文本
b64 encode --  hello               → 编码一个前导空格加 hello
uuid 3                             → 生成 3 个 UUID
hash MD5 hello                     → MD5 摘要
```

结果卡片点击复制完整结果，预览截断不影响复制；不会自动读取或改写剪贴板。关闭工具会移除其工具索引并阻止执行，系统可能仍保留动作名称。“清空索引并关闭”只影响 DevKit 的索引和开关，不清理其他应用。

首次设置说明：[Apple：为操作分配快捷短语](https://support.apple.com/zh-cn/guide/mac-help/mchl4953dfeb/26/mac/26)。
