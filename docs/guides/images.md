# 图片与网站图标

图片在本机处理。使用「选择图片」、拖入或粘贴来载入，调整参数后执行，最后从结果区复制图片或导出附件。

## 调整尺寸

「图片尺寸」提供三种方式：

| 模式 | 适用场景 |
| --- | --- |
| 等比缩放 | 放进指定宽高边界，保留完整画面 |
| 透明画布 | 保留完整画面，并填充到指定画布尺寸 |
| 居中裁剪 | 填满指定宽高，裁去超出部分 |

例如制作 800 × 600 的预览图：选择图片、填写宽高，按是否接受裁切选择模式。结果输出 PNG，导出前检查四周留白或裁切位置。

## 转换格式与压缩

「图片格式转换」支持 PNG、JPEG、HEIC 编码；当前不提供 WebP 编码。JPEG 的透明部分会合成为白色，动画或多帧图片只处理首帧。

「图片压缩」输出 JPEG，可以调整质量，也可以设置目标体积。目标体积无法达成时会明确提示；它不提供 PNG 无损压缩。需要透明度时，优先用 PNG 转换或尺寸调整。

## 查看与移除元数据

「图片信息」显示图片的元数据。选择移除元数据会重新编码图片，不能逐字段保留或删除。导出新文件后检查尺寸和画质；原文件不会被自动覆盖。

## 生成网站图标

在「网站图标」选择方形原图，生成多尺寸 PNG 与 ICO。可逐项导出，或使用「全部导出到文件夹…」一次保存到独立子文件夹。把导出的文件按自己的网站构建方式引用即可。

## 图片与文字互转

[Data URL](../tools/data-url.md) 可把图片变为 `data:image/...;base64,...`，也可以还原图片。解码保留原始图片字节和格式；不接受 SVG 或非图片载荷。

[二维码](../tools/qr-code.md) 可从文字或网址生成 PNG，也能从图片识别文本。生成时保留四周静区，放进网页或印刷材料后应再次扫描确认。
