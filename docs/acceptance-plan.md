# DevKit 测试与验收

日常交互验收唯一入口为 **Xcode → DevKit scheme → My Mac → Run（Debug）**。打包发布同样使用 Xcode 的 `Product → Archive` 和 Organizer，发布产物不与日常验收应用并行启动。

本文件定义未来验收要求，不记录为已执行的测试。验收以实际行为为准，文档、构建、元数据和系统界面分别提供对应证据。

## 验证层次

| 层次 | 验证内容 | 不能替代的内容 |
| --- | --- | --- |
| 核心逻辑 | 标准向量、格式边界、资源限制、取消与随机约束 | UI 操作或 Spotlight 系统交互 |
| 会话与集成 | 参数快照、状态迁移、过期任务、模块注册 | 真正安装后的系统行为 |
| 主窗口 UI | 编辑、复制、导入导出、标签、窗口、键盘与无障碍 | Spotlight 搜索与卡片交互 |
| 系统集成 | Spotlight A/B、Quick Keys、冷启动、结果复制与焦点 | 公开分发后的安装与升级 |
| 发布构建 | 最低系统、签名、资源、元数据、安装和升级 | 所有工具的业务正确性 |

## 需求追踪

| 已确认要求 | 验收方式 |
| --- | --- |
| 完整工具箱为主体 | 主窗口可独立完成已交付工具的完整流程，不依赖 Spotlight |
| Web 工具广泛覆盖 | 工具目录逐项记录交付状态和证据，分批数量与清单一致 |
| 一个工具一个模块 | 新增工具的代码集中在独立目录，测试和文档可定位到 ID |
| 苹果原生视觉与 Liquid Glass | 系统控件、材质层次、不同外观和辅助功能下截图与交互评审 |
| B 优先、A 同时支持 | 原生 Spotlight 中分别执行两条用户流程，包含配置前后状态 |
| 点击结果复制 | 点结果后的剪贴板字节与完整结果一致，并有反馈 |
| macOS 26+ | 至少在 macOS 26 真机验证最低系统，不以更高版本结果代替 |

## 主窗口关键用例

1. 中文和英文搜索、别名搜索、无结果、键盘选择、清除搜索。
2. 两个同类工具标签的输入和参数独立；切换后不丢当前会话内容。
3. 处理过程中修改输入或取消，旧结果不覆盖新内容，也不被当作当前结果复制。
4. 空输入、合法空输出、未执行与失败四种状态可区分。
5. 输入/输出切换、完整复制、选区复制、单条复制、批量复制与导出符合各工具约定。
6. 长文本或大结果只影响对应编辑区滚动，不改变整个窗口最小尺寸。
7. 拖入正确/错误文件类型、超限文件、取消文件选择、导出同名文件和部分批量失败。
8. 快捷键与菜单状态一致，不覆盖必要的编辑器和系统习惯。

## 代表性算法用例

| 工具 | 代表用例 |
| --- | --- |
| Base64 | 空文本、标准向量、中文/Emoji、URL Safe、完全省略填充、非法字符/填充、非 UTF-8、尾部 LF |
| URL | 参数/完整 URL/表单模式，`+` 与空格，`%` 截断、保留字符、重复编码与无效 UTF-8 |
| 哈希/HMAC | 标准向量、空文本、换行影响、密钥编码、文件流式结果与整块计算一致 |
| UUID/ULID/Nano ID | 格式、版本位、长度、数量和字符集；时序语义按支持的标准验证 |
| JSON/其他结构格式 | 深度、大整数、小数精度、重复键策略、错误位置、跨格式不能无损表达的字段 |
| JWT | 解码与验签状态分离、时间边界、未知算法、损坏签名、不能验证时不显示通过 |
| 文本与正则 | Unicode 字素、不同换行、零长度匹配、替换捕获、失控模式超时及取消 |
| 时间 | 秒/毫秒不混淆、UTC/本地时区、夏令时歧义、闰日、负时间戳 |
| 图形与文件 | 透明度、色彩空间、EXIF、方向、解码后超限、文件不被意外覆盖 |
| 网络 | 本地受控服务中的超时、重定向、认证、取消、断开与部分响应 |

每个模块还需要自己的完整测试集合；本表不是用一个通用测试覆盖所有工具的理由。

## Spotlight 强制用例

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| S01 | A 编码 | 搜索 Base64、选择编码、填写 `hello`、运行，系统卡片显示 `aGVsbG8=` |
| S02 | A 解码 | 选择解码，填写 `aGVsbG8=`，得到 `hello` |
| S03 | B 编码 | 首次配置后输入完整 `base64 encode hello`，得到正确结果 |
| S04 | B 用户样例 | 用户给的无填充字符串可解码，复制结果包含一个尾部 LF |
| S05 | 复制 | 直接点击结果区域复制完整值，截断预览不会导致截断复制 |
| S06 | 原文保留 | 多个空格、Unicode、引号、反斜杠、前后空白按冻结的命令规范处理 |
| S07 | 参数与错误 | 缺参数、未知操作、错误编码、超限等在系统内得到明确反馈 |
| S08 | A/B 共存 | 设置 `base64` Quick Key 后仍能通过约定流程选择编码/解码 |
| S09 | 生命周期 | 应用未运行、运行中、无主窗口时均能执行，且不抢焦点 |
| S10 | 结果稳定 | 结果重新渲染不重新生成随机值，不自动改写剪贴板 |
| S11 | 分发安装 | 安装到目标位置后的 Release 包能发现并运行动作 |
| S12 | 系统差异 | macOS 26 和后续版本的差异被记录，不能用高版本特性冒充最低版本能力 |

如果完整 B 受系统限制无法成立，记录失败证据和可行替代；只有用户同意变更后的目标才能调整验收用例。不能把“可在快捷指令里运行”写成 S03 已通过。

## 视觉与辅助功能

至少覆盖浅色、深色、不同系统强调色、减少透明度、减少动态效果、键盘全程操作和 VoiceOver。检查中文长标题、英文长单词、长错误、空态和加载状态。

窗口按视觉规范中的宽、中、窄尺寸验证；主要按钮始终可达，编辑器不反向撑大窗口。放大编辑器字体后重新检查参数栏、结果工具栏和焦点顺序。

## 资源与性能目标草案

以下是原型评估起点，需在指定机器与 Release 构建上测量后收敛，不是已有性能成绩。

| 场景 | 初始目标 |
| --- | --- |
| 主窗口冷启动 | Apple Silicon、16 GB 内存参考设备上，可交互时间目标不超过 2 秒 |
| 空闲与轻量操作完成后 | 无持续轮询、无后台自动转换；按 2026-10-11 用户要求，应用和辅助进程内存目标合计不超过 100 MB；同时记录处理峰值，不能将 Debug、Release、RSS 与 footprint 混为同一指标 |
| 普通文本操作 | 100 KiB Base64/URL/JSON 常规样本，计算与界面更新目标在 200 ms 内 |
| 长任务 | 及时展示忙碌状态；有实际取消路径；不阻塞窗口拖动和输入 |
| 初始主窗口文本上限 | 建议 5 MiB；自动转换阈值建议 64 KiB，具体模块可更低 |
| Spotlight 短输入 | 建议 16 KiB UTF-8；输出展示截断与完整复制分开 |
| 大文件摘要 | 验证流式内存占用不随整个文件大小线性增长 |

记录样本内容类型、大小、硬件、系统、构建模式、冷/热状态及多次结果。异常结果先分析算法和加载策略，再协商目标，不能靠删测试或伪造进度通过。

## 验收记录模板

每批记录：构建标识、系统/设备、模块范围、执行步骤、期望值、实际值、截图或日志、通过/失败/未执行，以及已知限制。涉及用户数据的测试使用可公开的样本，不把真实令牌或文件内容写进记录。
