# 常见问题

## 复制或导出按钮不能用

先确认工具已经成功执行，且结果没有标记「待更新」。修改输入或参数会使旧结果失效。再次执行完成后再复制；空输出和执行失败也应分别查看状态。

## Base64 解码失败

检查是否选了正确的标准 / URL Safe 模式、输入是否损坏。Base64 工具只返回 UTF-8 文本；图片应使用 Data URL。解码后不是 UTF-8 的二进制内容会被明确拒绝。

## URL 里的加号为什么变成空格

表单参数模式把 `+` 解释为空格，参数组件和完整 URL 的处理规则不同。根据来源选择模式，避免对同一段内容重复编码或解码。详见 [URL 编解码](tools/url-codec.md)。

## JSON 格式化成功，Schema 仍然失败

合法 JSON 只代表语法正确，Schema 还会检查类型、必填字段等规则。查看报告里的路径和失败原因，确认第二输入确实是需要使用的 Schema。

## 长文本只显示一部分

这是大文本分段编辑或预览截断。用上一段/下一段查看其他内容，复制全文和导出仍取得完整结果。JSON 折叠预览最多显示 10,000 个节点；更多边界见[工作区](workspace.md)。

## 切换工具或退出后内容在哪里

同一窗口内切换工具会保留会话；打开的独立窗口共享其来源工具的会话。退出应用或关闭该会话最后一个窗口后，不会自动恢复正文和密钥。需要保留请提前导出。

## 终端提示 command not found: devkit

在「设置 → CLI 与 AI」安装 CLI，然后新开终端。zsh / bash 会自动配置路径，其他 Shell 需把 `~/.local/bin` 加入 PATH。移动应用后更新链接。若提示已存在同名文件，请先检查它属于哪个工具，不要直接覆盖。详见 [CLI 安装](cli-and-ai.md#安装)。

## AI 没发现 Skill

先安装 CLI，再安装对应 AI 的 Skill，并重新打开 AI 会话。使用了自定义 Skill 目录时，将设置页提供的同一份 `SKILL.md` 放到 AI 实际使用的目录。

## HTTP、WebSocket 或 DNS 无法连接

核对地址、协议、端口和本机网络。HTTP 请求可能已完成但服务端返回了错误状态；DNS 自定义解析器需要填写 IP；WebSocket 地址必须是 `ws://` 或 `wss://`。CLI 还需要 `--allow-network`。用同一网络下可控的测试服务区分输入问题与目标服务问题。

## 图片变白、体积没降到目标值

JPEG 不支持透明背景，会合成为白色。需要透明度时使用 PNG。目标体积受原图内容、尺寸和画质限制，无法达成会提示；可以调整尺寸或质量后重试。

## Spotlight 没有 DevKit 动作

检查有效开发者签名、总开关和单工具开关，再确认你进入的是操作列表而不是普通搜索。系统 Quick Key 需要手动设置。当前完整系统交互仍有验证边界，见 [Spotlight](spotlight.md)。

## macOS 提示无法打开应用

先检查 macOS 是否达到 26，是否下载了完整的正式附件，以及 Release 是否明确说明该附件已签名和公证。系统报告包损坏或来源无法验证时，重新从该 Release 下载并核对校验值。把完整提示、系统版本和包名附到问题报告中。

## 如何反馈问题

在 [GitHub Issues](https://github.com/luolayo/devkit-macos/issues) 说明版本、macOS 版本、芯片架构、工具名称、最短复现步骤、预期与实际结果。只提供可公开的样例；不要上传真实令牌、密钥、内部地址或业务文件。
