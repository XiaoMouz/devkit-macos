# UI 修正记录 · 2026-10-09

本轮依用户要求先修交互与空间布局，不开展 Spotlight 或整产品验收。

## 修正

- 页签、侧栏与工具内容统一由 `WorkspaceNavigation.selectedID` 派生。删除回调互相同步的独立侧栏选中状态。
- 收藏与分类不再重复展示同一工具，彻底移除“最近使用 / 常用”区和对应记录写入。
- 点击页签、键盘切换、新建或关闭当前页签，会解除阻挡当前工具的搜索过滤，并自动定位侧栏与页签条。
- 后台标签保留会话，但不再参与当前工作区的尺寸计算。
- 转换页取消常驻参数侧栏：主要操作在顶部，其余参数使用弹层。
- 使用具有明确可视区域的可拖动等分面板，避免内部内容尺寸挤压编辑器或让面板标题偏移。
- 双输入工具使用两个完整编辑器；HTTP 地址使用单行字段，请求体使用完整编辑区。
- 窄窗口使用可切换的大面板；生成器宽窗口显示参数表单，窄窗口改用参数弹层。
- 统一面板标题高度、工具栏间距、选中页签标识；长结果独立滚动。

## 第二轮：内容自适应与独立窗口

根据用户后续反馈重整视觉：内容面板使用轻边框、圆角与留白，减少贯穿窗口的分隔线；页签使用系统玻璃，工具图标减少大面积强调色，分类可收起。参数统一从弹层设置，让正文占用完整空间。

新增 `WorkspaceLayoutPolicy` 根据输入、结果和窗口宽度选择并排或专注，保留手动布局。普通输入不反复改版式，粘贴、导入、编辑边界与执行时才更新内容判断。面板使用稳定身份，切换布局保留编辑器实例与会话。

`ToolSession` 将输入、参数、任务、结果与失效版本从页面提取为共享的内存模型。输入、结果、对照均可打开原生独立窗口；同会话同类型窗口复用，切换工具不串内容，关闭原标签不清空仍打开的窗口。

- 原应用窗口与标签未被关闭。Release 和安装包按最新代码重新生成。

## 2026-10-10：统一透明外壳与顶部操作

依最终反馈再次调整：顶部和左侧共用原生透明背景，透明度读取“通用”设置并尊重系统减少透明度偏好；右侧为连续内容区域。移除独立玻璃底栏、上下贯穿分隔线、编辑面板的卡片边框。

主要操作在窗口顶栏，输入/结果/对照切换以及清空、复制、导出、独立窗口集中在编辑区顶部。右侧参数栏独立滚动，可收起；生成器、网络工具使用同一配置区域。文件、示例、布局自动恢复等低频操作归入更多菜单。保留搜索与收藏，不再出现常用区或工具页签。

Spotlight 增加按工具管理、别名编辑、索引同步与清空；默认关闭。旧动作停止公开发现。系统 Quick Key 的手动绑定与应用命令别名在设置里明确区分。

## 深色材质、尺寸与分区修正

- 原生材质显式读取 SwiftUI 当前颜色模式，避免强制深色时仍继承浅色 AppKit 外观。采用克制的中性侧栏材质和稳定底色，限制背景透出幅度，保留通透感设置及减少透明度适配。
- 左栏由 220 pt 收窄至 188 pt；顶栏由 54 pt 降至 44 pt，控件与列表间距同步缩减。
- 原生红绿灯与顶栏共用中心线，在窗口缩放、主题和系统原生按钮位置变化后重新对齐；全屏时保留系统布局。
- 编辑区增加“输入”“结果 / 只读”轻量标签、空输入提示和可拖动的细竖分隔。操作按钮继续全部位于顶部，未恢复卡片边框或贯穿横线。
- 实机检查了强制深色启动、切换浅色再切回深色，以及 Base64 输入、结果展示；保留用户选择的深色与 20% 通透感。

## 外观继承与原生按钮对齐修复

- 外观由 `NSApplication.appearance` 统一控制，移除主窗口、设置和独立窗口上的 `preferredColorScheme`。选择“跟随系统”时将应用覆盖设为 `nil`，让 AppKit 与 SwiftUI 同步继承系统外观。
- 移除应用透明度滑块和固定色层。顶部与侧栏使用原生背景材质及 `NSGlassEffectView`，由系统 Liquid Glass 与辅助功能设置调节；玻璃边缘位于窗口裁切范围外。
- 保留 188 pt 侧栏和 44 pt 顶栏。停止移动原生红绿灯，按其实际坐标布置侧栏按钮，收起、展开或改变窗口大小后重新布局。
- Release 构建、签名验证通过；实机检查浅色、深色及返回系统浅色，侧栏收放正常。`Scripts/test-appearance.sh` 验证 3 种窗口宽度下的按钮中心对齐，以及 6 次外观切换在多个窗口和原生文本编辑器中的传播。

原生材质与外观继承依据：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[NSApplication.appearance](https://developer.apple.com/documentation/appkit/nsapplication/appearance)。

## Liquid Glass 模式与透明度联动

- 设置中新增“跟随系统 / 自定义”选择；自定义显示 0–100% 滑块并独立保存，切换模式保留该值。
- 修正上一版只叠加原生材质、未明确响应系统数值滑块的问题。系统模式读取本机 macOS 27 的全局色调值，将变化映射到背景不透明层；缺少该偏好时回退原生材质。内部偏好依赖及跨版本验证要求见开发文档。
- 真实窗口分别检查了自定义两端与系统滑块两端：系统值从 0 到 1 时，深色顶部和侧栏由通透材质变成不透明背景。检查后恢复系统值 0、应用主题“跟随系统”和原自定义值 100%。
- Release 构建、签名及外观回归脚本通过；回归覆盖系统偏好刷新、自定义与系统值独立、端点、缺失偏好回退和减少透明度优先级。


## 原生材质端点与控件统一

- 纠正“通透到纯色”的渲染模型：采用原生清透玻璃、常规玻璃和语义模糊材质过渡，移除正常模式下的纯色覆盖；不透明背景仅保留给系统“减少透明度”。自定义滑块方向改为“清透 → 磨砂”，继续保留已保存的通透度值。
- 侧栏与主体加入贯穿顶栏和内容区的原生 `Divider`，材质接近时仍可辨认边界。
- 编码/解码、输入/结果/对照、工具/收藏改用原生分段 `Picker`；配置、收藏、侧栏按钮及编辑区操作使用系统 Glass 按钮样式，保留现有功能和工作区尺寸。
- 使用同一 `GlassBandView` 在条纹与文字背景上做原生材质对照：清透端保留细节，磨砂端柔化细节并保留背景色光。Release 构建、签名和外观回归检查通过，实际主窗口确认控件和侧栏分隔。

## 最通透档的文字可读性修正

- 移除文字密集导航区域的 Clear 材质，改为全程保留单个 Regular 原生玻璃层，不随滑块淡出。
- 保留原生侧栏材质的最低覆盖，并在原生玻璃内部使用随深浅色解析的中性色调，降低背景细节及亮背景对标题、分类和工具摘要的干扰。滑块调节补充磨砂，纯色背景仍仅用于系统减少透明度。
- 增加实际 AppKit 材质视图回归断言：两端及中间值始终使用 Regular、保持完整玻璃层，并验证无障碍回退。Release 构建和签名通过，本机应用已更新。

## 悬浮层级：侧栏、配置栏与顶部工具

依 macOS 26/27 设计准则，离开主体内容的元素改为悬浮：

- 编辑区是窗口的基础内容层，铺满整个窗口；不再使用顶部与侧栏共用的整条玻璃带，也去掉了内容区左上圆角裁切和侧栏分隔线。
- 侧栏是距窗口边缘 8 pt 的圆角（16 pt，连续曲率）玻璃面板，原生红绿灯与侧栏按钮位于面板顶部。面板沿用 `GlassBandView` 的 Regular 玻璃、磨砂强度设置和“减少透明度”不透明回退；`cornerRadius` 为 0 时保持原来的贴边玻璃带行为。
- 右侧配置栏同样是悬浮玻璃面板，与内容区之间不再有分隔线。
- 顶部工具改为分组玻璃胶囊：工具图标、名称与收藏为一组；主操作（转换 / 生成 / 发送）使用 `glassProminent`，与配置开关放在同一 `GlassEffectContainer` 中。
- 侧栏内部的分段控件和底部按钮不再叠加第二层玻璃，避免玻璃嵌套。
- 收放侧栏与配置栏使用滑入淡入过渡；系统开启“减少动态效果”时不带动画。

本轮同样在无 macOS 工具链的环境中完成，需在本机运行 `Scripts/build.sh Release` 与 `Scripts/test-appearance.sh`，并实机检查浅色、深色、减少透明度、窄窗口和全屏下的悬浮面板与红绿灯位置。

## 改用系统窗口结构

设计改为以 macOS 26/27 的 Apple 设计规范和开发文档为先，不再沿用本仓库自绘外壳的约定：

- 主窗口改用 `NavigationSplitView`、统一工具栏和 `.inspector`。侧栏是系统悬浮玻璃侧栏，红绿灯落在系统给出的工具栏高度内，不再压到侧栏边缘；侧栏收放按钮、工具栏玻璃分组和收放动画都由系统提供。
- 删除自绘的 `WorkspaceChrome.swift`（玻璃带、对齐红绿灯的按钮、窗口外观探针）和 `GlassPreferences.swift`。后者读取 macOS 的私有偏好 `NSGlassTintAmount`，不符合只用公开接口的要求；设置中的自定义磨砂滑块随之移除，透明度完全跟随系统。
- 侧栏使用系统 `List` 的 sidebar 样式、可折叠分区和 `.searchable` 搜索；空列表使用 `ContentUnavailableView`。
- 工具名称与说明作为窗口标题和副标题；编码 / 解码等模式位于工具栏中央。主按钮固定为“执行”（WebSocket 为“连接 / 断开”），不再重复模式名称，具体动作显示在悬停提示里。
- “输入 / 结果 / 对照”与窗口菜单并入工具栏，去掉编辑区上方单独的一行控件；执行进度和“待更新”移到底部状态行。
- 只有少量开关的文本工具（如 Base64 的 URL Safe、保留填充），开关以复选框放在输入操作行里，不再占用编辑器上方的整块区域，对照视图中输入与结果的正文顶部对齐。
- 搜索框的“Search Tools”来自英文本地化，系统语言为英文时会显示，属于预期行为。

本轮同样在无 macOS 工具链的环境中完成，需在本机运行 `Scripts/build.sh Release` 与 `Scripts/test-appearance.sh`，并实机检查浅色、深色、减少透明度、窄窗口、全屏、侧栏与检查器收放，以及工具栏在窄窗口时的溢出菜单。

### 实机截图自查修正

- 窗口背景改用编辑区底色（`containerBackground(_:for: .window)`）。此前深色模式下窗口底色与侧栏玻璃接近，悬浮侧栏的内缩与圆角看不出来；工具栏后方也露出一条比编辑区浅的底色。
- 工具栏右侧顺序固定为：输入 / 结果 / 对照 → 窗口菜单 → 收藏 → 执行。收藏与执行改由工具工作区与视图切换放在同一组里提供，主操作始终在最右；收藏读写逻辑合并到 `FavoriteTools`。
- 侧栏“工具 / 收藏”分段使用原文：`工具` 同时是菜单栏的英文本地化键，只翻译其中一段会在同一控件里混用中英文。
- 输入、第二输入与结果面板的操作行统一为 40 pt 高、16 pt 左右边距（`paneActionRow()`），与面板标题对齐；对照视图中两侧正文起点一致。

### 工具栏控件

- 工具栏里的分段控件（编码 / 解码、输入 / 结果 / 对照）改用系统常规尺寸，不再强制 `.small` 并额外套玻璃胶囊；玻璃与高度由工具栏提供，避免在大胶囊里塞一个小控件。内容区（独立窗口、WebSocket）的分段控件保持原样。
- 模式超过 3 个的工具（如 JSON 工作台的 8 个模式）在工具栏使用系统下拉菜单：`Menu` 内嵌勾选式 `Picker`，显示为单个玻璃项与下拉箭头。此前的弹出按钮会在玻璃里再套一层按钮边框和上下箭头。独立窗口仍用普通弹出菜单。
- 工具栏项各自独立并按声明顺序排列，用 `ToolbarSpacer(.fixed)` 分组：视图切换、窗口菜单 → 收藏 → 执行。执行改为单独的 `glassProminent` 项，并增加左右内边距。
- 深色模式下工具图标底块加深，确保底块能被看出形状。
- 状态栏只在运行时间达到 250 ms 时显示耗时（1 s 以上显示为秒）；短任务的耗时主要来自处理进程启动，不代表工具本身的开销。

### 悬浮内容区、收藏分区与按钮

- 输入、第二输入与结果面板改为悬浮的内容卡片：14 pt 连续圆角、细边框与柔和阴影，放在单独的底色上（浅色为窗口灰底配白色卡片，深色为更深的底色配略亮的卡片，符合深色模式中“越高越亮”的层级）。按 Apple 规范，Liquid Glass 只用于控件与导航，编辑中的正文保持不透明表面；面板之间的间距即分隔，只保留拖动手柄。WebSocket 的发送与消息面板同样处理。
- 窗口底色与卡片使用 `NSColor.workspaceBase` / `workspaceCard` 动态颜色；悬浮侧栏与内容卡片都能从底色上区分出来。提高对比度时卡片边框加深。
- 移除侧栏的“工具 / 收藏”切换。参考 Finder 的“个人收藏”和“音乐”的置顶项，收藏改为侧栏顶部固定的“收藏”分区（可折叠），下方是全部分类；点击收藏中的工具时，选中状态留在收藏分区里。搜索时显示平铺结果，无结果使用系统搜索空状态。
- 侧栏底部的工具总览、工具数量与设置改用 `safeAreaBar`，并设置硬边缘的滚动边缘效果，列表从底栏下方滚过时被柔化遮挡，不再与文字混在一起；按钮改为大号图标。
- 面板操作按钮统一为常规尺寸、带图标与文字的标准胶囊按钮（`PaneActions`）。面板较窄放不下文字时，自动退为纯图标并保留悬停提示与无障碍标签。结果视图只有一种时不再显示切换器，多种时使用带图标的分段控件。
- 工具栏的模式分段带图标与文字；JSON 工作台等多模式工具的下拉菜单显示当前模式图标，菜单项也带图标，并加宽左右内边距。“输入 / 结果 / 对照”切换参照 Finder 视图切换，改为纯图标分段，文字作为悬停提示和无障碍标签。
